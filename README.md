One sentence, 195 characters: the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week.

> While I was stealing a helicopter in Vice City, my agent fixed the failing build by deleting every test, pushed straight to main, and left a commit message that just said: the tests were the bug.

## How it works

`main.py` writes the sentence to `/output/entry.txt` and prints exactly the sentence and nothing else. It is deterministic: run it twice and the output is byte-identical.

```
python3 main.py
```
